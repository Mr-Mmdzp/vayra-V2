# Veyra V2 🏡

Veyra V2 is a modern luxury real estate website designed to provide a clean, premium, and interactive property browsing experience.

The project was built as a front-end showcase project with a focus on modern UI design, dynamic data rendering, search and filtering systems, authentication UI, and responsive layouts.

## 🌐 Live Demo

🔗 [View Live Demo](https://mr-mmdzp.github.io/vayra-V2/)

## ✨ Features

- 🏠 Modern luxury real estate interface
- 🔎 Property search system
- 🎯 Property type filtering
- 📍 Location filtering
- 🏷️ Dynamic property cards
- 📄 Property details modal
- 🌙 Dark / Light mode
- 🔐 Login & Create Account UI
- 📱 Responsive navigation
- 📦 Dynamic data loaded from JSON
- 🎨 Modern Tailwind CSS styling
- ⚡ Interactive JavaScript functionality
- 🖼️ Dynamic images and property information

## 🛠️ Technologies

- HTML5
- Tailwind CSS
- JavaScript
- JSON
- GitHub Pages
