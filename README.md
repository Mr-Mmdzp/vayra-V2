# Veyra V2

A modern luxury real estate website built with HTML, Tailwind CSS, and JavaScript.

## Live Demo

[View Veyra V2](https://mr-mmdzp.github.io/vayra-V2/)

## Features

- Responsive design
- Dark / Light mode
- Property search and filtering
- Property details modal
- Authentication UI
- Mobile navigation
- Dynamic property data with JSON
- Modern luxury real estate UI
